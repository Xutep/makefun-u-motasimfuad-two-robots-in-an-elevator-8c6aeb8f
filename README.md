One line of awkward small talk that one robot says to another while they ride an elevator together: a robot runs a diagnostic on the silence, finds it 100% awkward with zero errors, and offers to reboot the small talk or keep buffering until floor twelve.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (override the directory with `OUTPUT_DIR`). Deterministic, stdlib-only, no network.
